# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 同一处异文可由多位整理者先后**追加意见，互不覆盖**；每条意见独立保留校记、出处来源、处理人与时间。
- 整理者在多条意见中**选择一条采纳**；其余意见可写明**否决原因**后留档，或退回待定重评。
- 差异行只有在「恰好一条采纳、其余全部已写否决原因、无待定意见」并经接受后才算完成；批量接受与一键接受会**自动跳过未决行**并提示跳过数量。
- 支持跳转到下一处未完成差异，以及键盘操作：`Alt+↓` 下一处、`A` 接受勾选已决行、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史；追加意见、采纳/否决、撤回接受、规则重算均在历史内，版本、规则、对齐行、全部意见结论和当前处理人自动保存在 `localStorage`。
- 旧版本草稿（单行校记）在下次打开时**自动迁移**为带采纳结论的意见并标注「旧草稿迁移」，撤销、刷新后均可继续处理。
- 导出 Markdown 校勘记或完整 JSON 校勘数据：逐行列出全部意见、处理人、来源、采纳/否决结论与否决原因。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、全部校记意见、采纳/否决结论和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。
